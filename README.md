## 🌟 Key Interactive Features

### 1. Interactive GoHighLevel Pipeline & Opportunity Management
- Live 5-stage opportunity board: *New Inbound Leads*, *Qualified & Scored*, *Follow-up Cadence*, *Call / Demo Booked*, and *Won / Closed*.
- Filter by GHL Tags (`tag:high-intent`, `tag:calendar-booked`, `tag:wa-engaged`).
- Detailed Opportunity Inspector displaying GoHighLevel custom fields, contact history, and active automated workflows.
- Ability to simulate GHL stage progression and action events.

### 2. Interactive GHL Workflow Lab ("Inside My Automation Workflows")
- Select between two real-world workflow pipelines:
  1. *Lead Capture to Appointment & WhatsApp Nurture* (8 nodes)
  2. *E-Commerce Webhook → n8n → Gemini AI Intent → CRM Sync* (5 nodes)
- Click any node to inspect trigger criteria, execution actions, conditional filters, and live simulated JSON output payloads.
- **Simulate Live Run** feature: Real-time visual execution stepper with live execution audit console.

### 3. AI + GoHighLevel Integration Architecture
- 4-Tier Blueprint:
  1. *Layer 1: Ingestion & Omnichannel Inbound* (Forms, Webhooks, WhatsApp, E-commerce)
  2. *Layer 2: Middleware & Orchestration Hub* (n8n, Make, Custom Proxy)
  3. *Layer 3: AI Intelligence Layer* (Google Gemini, OpenAI GPT-4o, Prompt Guardrails)
  4. *Layer 4: GoHighLevel CRM Core & Delivery* (Pipelines, Twilio, Calendars)
- Technical specifications covering HMAC webhook signatures, idempotency, retry mechanisms, and rate limits.

### 4. Featured Project Case Studies
- **Nosh AI — CRM & AI Automation:** Sales pipelines, e-commerce sync, and automated multi-touch communications.
- **DHJ Insurance — Agentic Automation System:** Comprehensive state-machine architecture for conversational voice agents (clearly distinguishing planned architecture from production-deployed features).
- **Online Water Filters — WooCommerce Automation:** Operational automations, form stabilization, and staging-to-production migration.
- **AI Interview Prep — Full-Stack Web App:** Live application on Vercel powered by Gemini AI with GitHub repository link.

### 5. Services & Contact Engine
- 7 specialized GoHighLevel & AI services with clear deliverables.
- Interactive contact form with validation and direct one-click WhatsApp / Email dispatching.

## 💻 Local Setup & Development

### Prerequisites
- Node.js 18+ or 20+
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/ahmedmehboob811/new-portfolio.git

# Navigate into the project folder
cd new-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

The app will start at `http://localhost:3000`.

### Build for Production
```bash
npm run build
```
